## Phase 7: Drift Detection

### Purpose

After Phase 6 delivers the final spec, the codebase continues to evolve. Phase 7 detects which spec sections are potentially affected by source code changes, by cross-referencing `git diff` (or hash snapshots) against `source-map.json` and `trace.json`.

### Prerequisites

- `.specback/` directory with `source-map.json` and `trace.json` (generated by Phase 4 / build-trace.py)
- Phase 6 must have completed (final spec exists)
- `git` repository (for git mode) OR `source-hashes.json` (for hash mode)

### Procedure

1. **Mode detection** (auto)
   - `--mode` explicit flag → use that mode
   - Git repo + `state.json.generated_at_commit` present → **git mode**
   - `.specback/source-hashes.json` exists → **hash mode**

2. **Run detect-drift.py**
   ```bash
   python .specback/skill/scripts/detect-drift.py \
     --specback-dir .specback \
     --output-dir {output_dir}
   ```

3. **Review output**
   - `{output_dir}/drift-report.md` — human-readable report listing affected spec sections with impact level (high / moderate / low)
   - `{output_dir}/drift-report.json` — machine-readable version

4. **Ask user** (using AskUserQuestion):
   - "Drift report generated. {N} spec section(s) affected. Would you like to auto-correct REF line numbers? (Phase 7b)"
   - Choices: Yes (proceed to Phase 7b) / No (complete)

5. **If Yes**, proceed to Phase 7b below.

### Usage examples

```bash
# Default (auto mode: git if available, hash if source-hashes.json exists)
python .specback/skill/scripts/detect-drift.py --specback-dir .specback

# Explicit git mode
python .specback/skill/scripts/detect-drift.py --specback-dir .specback --mode git --base v1.0

# Hash mode (non-Git projects)
python .specback/skill/scripts/detect-drift.py --specback-dir .specback --mode hash

# Pipe diff from CI
git diff --name-status main...HEAD | python .specback/skill/scripts/detect-drift.py --diff -

# JSON output
python .specback/skill/scripts/detect-drift.py --specback-dir .specback --json
```

### Output

- `{output_dir}/drift-report.md` — summary table with file, SRC-ID, impacted sections, impact level, and recommended action
- `{output_dir}/drift-report.json` — structured data for tooling

See `references/drift-detection.md` for the full design document.
